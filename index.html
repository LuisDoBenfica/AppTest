Mise à niveau Windows 10 → 11

Mise à niveau en place, conservant applications et fichiers.

  1. Vérifier UEFI, Secure Boot et TPMmsinfo32 tpm.msc
  2. Si le mode BIOS est « Hérité », convertir en GPTmbr2gpt /validate /allowFullOS
    mbr2gpt /convert /allowFullOS
    Puis activer UEFI et Secure Boot dans le BIOS Dell (F2).
  3. Suspendre BitLockermanage-bde -protectors -disable C:
  4. Assainir l'image WindowsDISM /Online /Cleanup-Image /RestoreHealth
    sfc /scannow
  5. Lancer l'installation depuis WindowsMonter l'ISO ou ouvrir la clé, puis exécuter setup.exe et choisir « Conserver les fichiers personnels et les applications ».

Démarrer sur la clé USB ne permet qu'une installation propre : l'option de mise à niveau n'y est pas proposée.

ℹ️Informations système6
msinfo32

Mode BIOS (UEFI/Hérité), état du Secure Boot, modèle, version du BIOS.

winver

Version et numéro de build de Windows.

systeminfo

Résumé complet : OS, date d'installation, correctifs, mémoire.

tpm.msc

Présence, état et version du TPM.

whoami /all

Utilisateur courant, groupes et privilèges. hostname pour le nom du poste.

Get-CimInstance Win32_BIOS

PSNuméro de série (Service Tag Dell) et version du BIOS. Remplace wmic bios get serialnumber, déprécié.

🛠️Réparation et intégrité5
DISM /Online /Cleanup-Image /RestoreHealth

Répare l'image Windows. À lancer avant sfc si celui-ci échoue.

sfc /scannow

Vérifie et répare les fichiers système protégés.

chkdsk C: /f /r

Vérifie le disque et récupère les secteurs défectueux (planifié au redémarrage pour C:).

bcdedit /enum

Affiche la configuration de démarrage. bcdboot C:\Windows la reconstruit.

reagentc /info

État de l'environnement de récupération WinRE.

💽Disques et partitions6
diskpart

Gestion des disques. list disk : un * dans la colonne GPT indique un disque GPT.

mbr2gpt /validate /allowFullOS

Vérifie si la conversion MBR → GPT est possible.

mbr2gpt /convert /allowFullOS

Convertit le disque système en GPT sans perte de données.

manage-bde -status

État du chiffrement BitLocker des volumes.

manage-bde -protectors -disable C:

Suspend BitLocker jusqu'au prochain redémarrage (avant BIOS/mise à niveau).

cleanmgr

Nettoyage de disque, utile pour libérer de l'espace avant une mise à niveau.

🌐Réseau9
ipconfig /all

Configuration IP complète, adresse MAC, DNS, DHCP.

ipconfig /flushdns

Vide le cache DNS local.

ipconfig /release && ipconfig /renew

Libère puis renouvelle le bail DHCP.

ping -t hôte

Test de connectivité continu (Ctrl+C pour arrêter).

tracert hôte

Trace la route. pathping ajoute les pertes par saut.

nslookup nom

Interroge le DNS pour un nom ou une adresse.

netstat -ano

Connexions et ports ouverts avec le PID associé.

Test-NetConnection hôte -Port 443

PSTeste l'ouverture d'un port TCP.

route print

Table de routage. arp -a pour la table ARP.

🏢Domaine, GPO et comptes6
gpupdate /force

Applique immédiatement les stratégies de groupe.

gpresult /r

GPO appliquées au poste et à l'utilisateur. /h rapport.html pour un rapport.

nltest /dsgetdc:domaine

Contrôleur de domaine utilisé par le poste.

dsregcmd /status

État de jonction Entra ID (Azure AD) et hybride.

net user

Liste les comptes locaux. net user nom /domain pour un compte du domaine.

net localgroup administrators

Membres du groupe Administrateurs local.

⚙️Processus, services, alimentation6
tasklist

Liste des processus en cours avec leur PID.

taskkill /PID 1234 /F

Force l'arrêt d'un processus (ou /IM nom.exe).

sc query nom_service

État d'un service. net start / net stop pour le piloter.

shutdown /r /t 0

Redémarrage immédiat.

shutdown /r /fw /t 0

Redémarre directement dans le firmware UEFI (BIOS).

powercfg /batteryreport

Rapport d'usure de batterie (portables). /energy pour un diagnostic énergie.

🔄Mises à jour et logiciels4
winget upgrade --all

Met à jour toutes les applications gérées par winget.

winget list

Inventaire des logiciels installés.

UsoClient StartScan

Déclenche une recherche Windows Update.

wusa /uninstall /kb:1234567

Désinstalle un correctif identifié par son numéro KB.
